# Notion Page Navigator

ブラウザ版 Notion のページを読みやすくする Chrome 拡張です。次の2つを追加します。

- **右側のペイン**：ページの見出し一覧（Outline）、このページからのリンク先（Forward links）、このページへのリンク元（Backward links）を表示します。
- **本文の装飾**：ブロックごとの行番号、コードブロック内の行番号、見出しの左に見出しレベルを示す縦棒（H1 は1本〜H4 は4本）を表示します。

対象は Chrome で開いた `https://app.notion.com`、`https://www.notion.so`、`https://notion.so` のページです。

## インストール

Chrome ウェブストアには公開していません。次のどちらかの方法で読み込みます。

**Releases の ZIP から**

1. GitHub の Releases から `notion-page-navigator-v<バージョン>.zip` をダウンロードして解凍します。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、解凍したフォルダ（`manifest.json` があるフォルダ）を選びます。
4. 開いている Notion のタブを再読み込みします。

**ソースから**

このリポジトリを clone し、上の手順3で `extension` フォルダを選びます。ビルドは不要です。

## 使い方

### ペイン

- Notion 上部の「共有」ボタンの左にあるアイコンで、ペインを開閉します。
- Outline の見出しを押すと、その見出しまで移動します。今読んでいる位置の見出しが強調されます。
- Forward links と Backward links の項目は、クリックすると同じタブでそのページへ移動します。⌘（Windows では Ctrl）を押しながらのクリックや中クリックでは、新しいタブで開きます。
- 各セクションは見出しを押すと折りたためます。セクションの境界をドラッグすると高さを、ペインの左端をドラッグすると幅を変えられます。

### 設定

ツールバーの拡張アイコンから設定画面を開きます。変更はすぐに反映されます。

| 項目                     | 内容                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------- |
| セクション               | Outline・Forward links・Backward links のそれぞれを表示するか                           |
| 本文の表示               | 行番号（ブロック単位）、コードブロックの行番号、見出しの縦棒を表示するか                |
| ページの先頭へ戻るボタン | 下へスクロールしたとき、右下に先頭へ戻るボタンを出すか                                  |
| NotionのAIボタンを隠す   | 右下のNotion AIのボタンを隠すか。ペインを開いている間、このボタンはペインの左へ移します |
| 配色                     | Notion に合わせる・ライト・ダーク                                                       |
| 色                       | アクセント・見出しの縦棒の色、行番号の色                                                |
| ペイン幅                 | 240〜720px                                                                              |

行番号用のカスタム CSS を別の拡張で読み込んでいる場合は、二重に表示されるので外してください。

## データの扱い

- ページの内容とリンク元は、ログイン中の Notion から読み取ります。通信先は Notion（上の3つのドメイン）だけです。
- ページの内容を書き換えることはありません。
- 読み取った内容はタブの中だけで使い、保存しません。
- 保存するのは設定（表示する項目、色、ペインの幅と高さ）だけで、保存先は Chrome の拡張用ストレージ（`chrome.storage.local`）です。
- 必要な権限は `storage` だけです。分析・広告・外部スクリプトは含みません。

## 制約

- Notion の画面や仕組みが変わると、正しく動かなくなることがあります。
- 動作確認は日本語表示の Notion で行っています。
- Notion デスクトップアプリ、Notion Sites などの公開ページ、独自ドメインには対応していません。
- サイドピークでページを開いている間は、ペインと行番号・見出しの縦棒・コードブロックの行番号はピーク側のページが対象になり、ピークをペインの左へ寄せます。裏にあるページの行番号などは、ピークを閉じるまで消えます。中央に開くピークは未確認です。
- 行番号について：
  - 閉じたトグルの中のブロックは数えません。トグルを開くと番号が振り直されます。
  - データベースの中には番号を付けません。
  - 段組みの2列目以降では、番号とブロック横のハンドル（＋、⋮⋮）が近く、重なって見えることがあります。
- コードブロックの行番号について：
  - 改行で区切った行ごとに番号を振ります。「折り返し」がオンのとき、折り返した続きには番号を付けません。
  - 番号の分だけ、コードの左の余白を広げます。
  - コードをコピーしても番号は含まれません。
- Backward links では、閲覧権限のないページは表示しません。
- Forward links と Backward links に表示するのは、それぞれ最大2,000件です。
