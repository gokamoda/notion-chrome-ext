# Notion Forward & Backlinks — ローカルMVP

Chrome Manifest V3拡張。右側の固定パネルに本文のリンク先とNotion標準のリンク元一覧を表示します。依存パッケージ・ビルド・APIキーは不要です。ストア公開はしていません。

**取得範囲付きのMVPです。ページ全体の完全なリンク一覧を保証しません。** Forward linksは描画済み本文、Backlinksは開かれた標準一覧を読み取ります。未取得を0件にはしません。

## 読み込み

1. Chromeで `chrome://extensions` を開き「デベロッパーモード」を有効化。
2. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリ内の **`extension` フォルダ**を選択。
3. ブラウザ版Notionのタブを再読み込み。Notionへのログインは通常の画面で行ってください。認証情報を拡張やチャットへ入力する必要はありません。
4. 修正後は拡張一覧の更新アイコンを押し、Notionのタブも再読み込み。

対象は `https://app.notion.com/*`、`https://www.notion.so/*`、`https://notion.so/*` のみ。Notionデスクトップアプリ、公開Notion Sites、独自ドメインは対象外です。

## 使い方

- 右上の **Page links** を使用。パネルは本文に重ねて表示するため、狭い画面では「閉じる」で折りたたんでください。「Linksを開く」で戻せます。
- Forward linksは本文描画・編集に合わせて更新します。項目は安全のため別タブで開きます。元タブ内でNotionを移動しても、そのページへ追従します。
- **Backlinksの初回取得**：Notionのページ先頭に移動し、拡張の「標準Backlinksを開く」またはNotion自身の「○個のバックリンク」を押してください。展開された「リンク元ページ」を読み取ります。Notion側の表示が非表示ならページの外観・レイアウト等のバックリンク表示設定を確認してください。UI配置はNotionのバージョンで異なります。
- 標準一覧は閉じても、取得した項目をパネルに保持します。取得時刻が表示されます。再取得は標準一覧を開き直してください。別ページへ移動すると消去され、そのページで再取得が必要です。**ページ移動ごとの自動Backlinks展開はしません。**
- 「更新」は両方向のメモリ内スナップショットを破棄して再収集します。標準一覧が閉じているとBacklinksは未取得へ戻ります。
- 長いページは「長い本文を走査」。先頭から末尾へスクロールし、描画されたリンクを収集します。最大120ステップ（待機だけで約30秒）。終了時に元のスクロール位置へ戻ります。再クリックで中止。ホイール・タッチ・キー入力でも中止します（ユーザー操作時は位置を戻しません）。タブを隠した場合も停止します。
- 配色はNotionのテーマを優先し、OS設定を補助に使用。「配色」ボタンで明示的にライト／ダークを選べます。設定はタブの再読み込みで初期化します。

## 取得方式と調査結果（2026-11-12）

### 実際のChromeで観察したもの

日本語UIのログイン済み `app.notion.com` 上で以下を読み取り確認しました。ページ本文・設定内容は変更していません。

- 本文の `.notion-page-content`、本文ブロックの `data-block-id`、現在ページのタイトルブロック `.notion-page-block[data-block-id]` を確認。
- インラインページメンションは `a.notion-page-mention-token` で、`/p/{page_id}?pvs=24` のhrefを持つことを確認。
- 本文の一部だけがDOMに存在し、スクロール／ウィンドウ状態により描画ブロック範囲が変わることを確認。初回DOM一括走査だけでは取りこぼします。
- 本文のメンション先へ実際にページ移動し、「3個のバックリンク」を開いて標準の「リンク元ページ」ダイアログを確認。
- 標準一覧は `[role="dialog"]` 内にNotionページへの `a[href]` を持ち、ページ名はその中の `div.notranslate`、パンくずは別要素でした。参照箇所数と一覧のページ数が同じとは限りません。
- 標準ボタンは `[role="button"][aria-haspopup="dialog"]` でした。ボタン文言とダイアログの見出しを組み合わせて識別します。無関係の検索結果等はBacklinksにしません。

通信・内部APIは採用していません。セッショントークン・Cookieを読むコードもありません。

### Forward links

本文領域内の `a[href]` だけを読みます。ページメンション・通常のページリンク・リンクブロックがhref付き要素として描画される場合を含みます。ナビゲーション、パンくず、本文外のプロパティ、埋め込みDBのテーブル／グリッドを除外します。外部リンクはホスト名で拒否します。ページIDで重複排除し、URLのクエリ・ブロックアンカー・UUIDのハイフン差を無視します。

同一タブ・同一ページで描画されたブロックのスナップショットだけをメモリに持ちます。画面外へ仮想化されたブロックのリンクも保持します。描画中のブロックの編集は置換しますが、画面外の削除は検出できないため「更新」で再収集してください。これはBacklinksの逆引きには使用しません。

### Backlinks

Notion自身の標準一覧をユーザーが開いたときに読み取り、現在ページだけのスナップショットをタブ内メモリに保持します。「標準Backlinksを開く」は確認済みの標準ボタンをクリックするだけです。Notionの内容は変更しません。

一覧未検出、他ダイアログ表示、読み込み、リンク要素なし、権限不足、DOM変更を全件0件と扱いません。リンクのない標準一覧の確実な空状態は実機で確認できていないため、**Backlinks全件0件の確定表示は実装していません**。Forward linksでは「描画済み本文では0件」と範囲を明示します。

### 公式APIを採用しなかった理由

[Retrieve block children](https://developers.notion.com/reference/get-block-children) は本文の子ブロック取得に利用できますが、接続用の別認証とページへのアクセス許可、入れ子・ページネーションの処理が必要です。今回確認した公式API資料からは、Notion標準のBacklinksを直接取得できるエンドポイントは確認できませんでした。別途認証しても本件のBacklinksの完全取得を満たす根拠がないため、初版には含めていません。APIキーの設定は不要です。

標準機能の説明：[Notion公式 — Links & backlinks](https://www.notion.com/help/create-links-and-backlinks)。この資料はリンクとバックリンクの機能を説明しており、DOMや内部APIの互換性を保証するものではありません。

## 制約

- 常に「範囲のみ／全件未確認」を表示します。長い本文の末尾に到達しても完全取得とは表示しません。閉じたトグル、遅延読み込み、同期ブロック、権限のないページ、hrefのないクリック専用要素などは未取得の場合があります。トグルを勝手に開きません。
- Backlinksは標準一覧の**描画済み項目**のみ。大量のリンク元の仮想スクロール・ページネーションは全件対応していません。一覧をスクロールした際の最新描画範囲で置換します。標準ボタンの件数は参照箇所数である可能性があるため、ページ数との一致による完全性判定はしません。
- Forwardの保持上限は2,000ブロック／2,000リンク先ページ。Backlinksのパネル表示上限も2,000ページ。到達した場合は画面に表示します。
- 表示名はリンクのラベルです。通常のテキストリンクで独自ラベルを付けていた場合、リンク先の正式なページ名は取得できません。名前が空なら短縮ページIDと取得不可を表示します。
- 複数ページのサイドピーク表示では誤混入を避けるため取得不可にします。通常のページ表示に戻してください。
- 日本語UIで実DOMを確認しました。英語UIの見出し・ボタン候補も実装していますが未検証です。その他の言語は非対応。
- 旧 `notion.so` のDOM互換性、リンクブロックの実DOM、複雑なDBリレーションは未確認。リレーションは対象外であり、Notionが構造を変更した場合は除外判定の調整が必要です。
- Notionの内部DOMは非公式です。変更時は `extension/notion-dom.js` を修正してください。

## プライバシー・構成

- 外部ライブラリ、分析、広告、外部スクリプト、追加権限、background worker、外部通信コードなし。
- パネルのページ文字列は `textContent` で描画し、URLは許可ホスト・HTTPS・ページID形式を検証。任意HTMLは挿入しません。
- 内容・認証情報を第三者へ送信せず、ディスク・Chrome storage・localStorageにも保存しません。複数タブ間で内容を共有しません。
- DOM変更はまとめて処理し、原則約800msに1回まで再走査。非表示タブでは走査を止めます。1秒ごとのタイマーはURL比較だけです。自動通信はありません。
- `core.js`: URL検証・重複排除。`notion-dom.js`: Notion固有構造。`content.js`: UI・監視・スナップショット・スクロール走査。

## 検証

```sh
node --test tests/core.test.cjs
python3 -m http.server 8765 --bind 127.0.0.1
# ブラウザで http://127.0.0.1:8765/tests/browser.html
```

URLの安全性・重複排除はNode標準テスト、DOM判定は外部依存のない合成HTMLテストを用意しています。合成テストは実Notionの互換性証明とは別です。

**Chromeへ読み込み済み。** 実Notionで両方向の取得、ページ移動、更新・開閉、配色切替、本文末尾までの走査、別タブの独立性を確認しました。名前抽出時の空アイコン要素によるパンくず混入も実機で修正・再検証しました。実データでの0件／権限不足、リンクブロック、走査中止、極端に長いページと大量Backlinksは未確認です。範囲内0件／取得失敗と重複排除は合成テストでも確認。詳細は [TESTING.md](TESTING.md) を参照してください。
